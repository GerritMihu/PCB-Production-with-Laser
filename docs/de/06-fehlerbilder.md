# Fehlerbilder

🇬🇧 [English](../en/06-defects.md) · [← Übersicht](../../README.de.md)

| Fehler | Mögliche Ursache | Abhilfe |
|---|---|---|
| Kupferreste zwischen Bahnen | zu wenig Leistung / zu wenige Durchgänge, Fokus falsch | Durchgang wiederholen, Fokus prüfen |
| Substrat verbrannt / dunkel | zu viel Leistung, zu viele Durchgänge | Leistung reduzieren |
| Leiterbahn unterbrochen | Bahn zu dünn, Kupfer abgetragen | Bahnbreite ≥ 0,4 mm, Kantenparameter prüfen |
| Brücken zwischen Pads | Abstand zu klein, Füllung unvollständig | Clearance prüfen, Füllmuster/Linienabstand anpassen |
| Bild verschoben/verzerrt | Platine nicht plan, falscher Maßstab | Platine fixieren, Maßstab nach Import prüfen |
| Ober- und Unterseite passen nicht | Ausrichtung beim Umdrehen | Passmarken/Anschlag verwenden |
| Kupfer löst sich beim Löten | Hitze, fehlende Teardrops | Teardrops, Lötkolbentemperatur senken |
