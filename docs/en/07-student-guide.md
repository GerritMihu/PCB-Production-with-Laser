# Student Quick Guide

🇩🇪 [Deutsch](../de/07-schueler-anleitung.md) · [← Overview](../../README.md)

**From KiCad design to finished board – in 10 steps.**

1. Create a **new project from template** *Laser_PCB_xTool*. Do not change any rules yourself!
2. Draw the schematic, assign footprints.
3. Lay out the board: outline on `Edge.Cuts`, route tracks.
4. Add a **ground plane** (GND).
5. Run **DRC** → 0 errors.
6. Export the files (ask your teacher or see [Export](04-export.md)).
7. Together with your teacher: place the board in the laser, extraction **on**, start the job.
8. Clean the board (isopropanol + toothbrush).
9. Check with the multimeter: no shorts between neighbouring tracks.
10. Drill, assemble, solder. 🎉

> ⚠️ Only operate the laser with a teacher present. Never look into the running laser or open the lid.
